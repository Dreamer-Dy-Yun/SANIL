# Backend Docs

## 역할

`backend/docs/`는 백엔드 구현 전에 합의해야 하는 계약, 설계 기준, 모듈 경계를 기록한다.

## 문서 목록

| 경로 | 역할 | 갱신 기준 |
|---|---|---|
| `api/` | 백엔드 API 경계 초안 | API 요청/응답, 인증/권한, 오류 형식이 바뀔 때 |
| `database/` | 산일전기 DB 설계 문서의 로컬 기준화 | 테이블, 필드, 관계, 제약, DB 책임 경계가 바뀔 때 |

## 갱신 규칙

- 백엔드 구현이 API 계약, DB 스키마, 인증/권한, 에러 형식을 바꾸면 관련 문서를 같은 작업에서 갱신한다.
- 프론트와 공유되는 값은 임의로 숨기거나 변환하지 말고 계약 문서에 드러낸다.
- 원본 설계서와 구현이 달라지는 경우, 차이와 이유를 문서에 남긴다.
