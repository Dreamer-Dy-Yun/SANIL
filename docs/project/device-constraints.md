# Device Constraints

## Target Device

고객사가 사용할 촬영 장비는 `M86XE` 계열 태블릿으로 본다.

사용자가 제공한 표기는 `М86ХЕ`이며, 시각적으로는 `M86XE`와 같지만 일부 문자가 키릴 문자일 수 있다. 문서와 코드 식별자에서는 검색성과 입력 오류 방지를 위해 Latin 표기 `M86XE`를 우선 사용한다.

## Known Display Baseline

사용자 확인 기준으로 1차 UI 기준 viewport는 다음처럼 둔다.

| 항목 | 기준 |
|---|---|
| 화면 크기 | 8 inch |
| 패널 | IPS |
| 해상도 | 1280 x 800 |
| 화면비 | 16:10 |
| 밝기 | 700 cd/m2 |
| 터치 | 10-point capacitive |

이 기준은 layout breakpoint와 현장 조작 크기를 잡기 위한 1차 값이다. OS/browser의 실제 CSS viewport와 카메라 권한 동작은 실기에서 다시 확인한다.

## Design Impact

- 1차 UX는 태블릿 현장 사용을 기준으로 한다.
- 촬영 화면은 한 화면 한 단계 구조를 유지한다.
- 주요 조작 버튼은 장갑 착용, 현장 조명, 한 손 조작 가능성을 고려해 충분한 터치 영역을 가져야 한다.
- 1280 x 800 landscape에서는 데스크톱 사이드바를 고정 노출하지 않고 상단 메뉴 버튼과 drawer navigation을 사용한다.
- 제품 선택 화면의 검사 시작 액션은 한 곳으로 모아 오조작을 줄인다.
- 제품 선택 화면의 바코드/QR 입력은 단순 실행 버튼이 아니라 카메라 프레임을 기본 노출하는 구조로 둔다.
- 카메라 입력은 우선 브라우저 `getUserMedia` 기반으로 설계하되, 실제 장비의 기본 브라우저/Chrome/WebView 지원 여부를 실기에서 확인한다.
- 기준 사진 오버레이와 QA 대상 촬영 이미지는 동일한 `origin: "top_left"`, `unit: "ratio"` 좌표 계약을 사용한다.

## Verification Items

실기 또는 고객 제공 사양서로 다음 항목을 확인해야 한다.

- OS 버전
- 기본 브라우저와 Chrome 설치/업데이트 가능 여부
- `getUserMedia` 카메라 권한 동작
- 후면 카메라 해상도와 초점/노출 제어 가능 범위
- 촬영 화면의 실제 viewport 크기와 orientation
- 네트워크 환경: Wi-Fi, LTE/5G, 사내망 접근 방식
- 장비 보안 정책: 카메라 권한, 파일 다운로드, 브라우저 저장소 제한

## Current Position

M86XE 장비명과 1280 x 800 landscape 기준은 촬영 UX의 기준 제약으로 반영한다.

다만 OS/카메라/브라우저 세부값은 임의 확정하지 않는다. 구현 전에는 실제 장비 또는 고객 제공 사양서를 기준으로 촬영 PoC를 수행한다.
