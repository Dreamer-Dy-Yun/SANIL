# SANIL Docs

## 역할

`docs/`는 SANIL 프로젝트의 제품 배경, 범위, 요구사항, 기술 판단을 기록한다.

## 문서 목록

| 경로 | 역할 | 갱신 기준 |
|---|---|---|
| `project/` | 프로젝트 배경, 범위, 기능 흐름, 기술 판단 | 고객 요구, 범위, 제품 방향, 주요 의사결정이 바뀔 때 |

## 갱신 규칙

- 고객 요구나 제외 범위가 바뀌면 관련 프로젝트 문서를 같은 작업에서 갱신한다.
- 구현 문서는 `frontend/`, `backend/` 경계 문서와 연결해서 유지한다.
- 불명확한 요구는 임의로 구현하지 말고 open question 또는 risk로 남긴다.
