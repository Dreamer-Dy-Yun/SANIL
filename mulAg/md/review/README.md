# Review

## 역할

`review/`는 Sub-Agent가 작업 결과와 검증 내용을 기록하는 위치다.

## 필수 항목

- 수행 일시
- 참조 plan
- 참조 todo
- 수행 내용
- 변경 파일
- 생성 파일
- 미변경 파일
- 변경 요약
- 검증 내용
- 남은 이슈
- QA 확인 요청 사항

## 처리 기준

- QA는 review와 실제 파일 상태를 함께 검토한다.
- review 내용과 실제 파일 상태가 다르면 실제 파일 상태를 우선한다.
- 승인된 review는 `md/done/`에 작업 결과로 정리한다.
- 반려된 review는 `rejected/`로 이동한다.
