## 목적

제품 선택 화면의 하단 액션을 단일 버튼으로 정리하고, 촬영 화면의 촬영 지시를 촬영 영역 위로 이동한다.

## 범위

- `/products` 화면의 CTA 버튼을 하나로 통합한다.
- 제품 미선택 상태에서는 단일 CTA가 코드 촬영을 수행한다.
- 제품 선택 상태에서는 같은 CTA가 검사 시작을 수행한다.
- 제품 선택 화면의 select, 선택 상태, CTA 터치 영역을 작업자 태블릿 기준으로 키운다.
- `/inspections/:inspectionSessionUuid/capture/:stepOrder` 화면의 촬영 지시는 촬영 이미지 영역 안이 아니라 그 위에 둔다.

## 제외

- API 계약 변경
- mock fixture 변경
- 백엔드/DB 변경
- 실제 카메라/스캐너 구현체 변경

## 완료 기준

- 제품 선택 화면 하단 CTA가 하나만 존재한다.
- 제품 미선택 시 CTA 문구는 `코드 촬영`이고 코드 촬영을 수행한다.
- 제품 선택 시 CTA 문구는 `검사 시작`이고 검사 세션을 시작한다.
- 촬영 지시는 촬영 영역 위에 배치된다.
- lint, test, build, 1280 x 800 화면 검증, 배포 확인을 통과한다.
