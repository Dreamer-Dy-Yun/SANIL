# Archived Plans

## 역할

완료되지 않았지만 active 상태로 유지하지 않을 plan을 보관한다.

## 하위 폴더

| 경로 | 역할 |
|---|---|
| `canceled/` | 폐기된 계획 |
| `deferred/` | 보류된 계획 |
| `superseded/` | 다른 계획으로 대체된 계획 |

## 대체 plan 기록

대체된 plan에는 다음 항목을 남긴다.

```markdown
## archived reason

superseded

## replaced by

PLAN-{YYYYMMDD}-{연번}
```
