## todo 분해 기준

- 프론트 화면 설계와 mock/API adapter 경계는 별도 todo로 분리한다.
- 백엔드 API 계약 설계는 DB 설계 문서와 연결해 별도 todo로 분리한다.
- 기능별 todo는 `functional-decomposition.md`의 기능 경계를 기준으로 분리한다.
- 의존성 조립 또는 factory 파일은 한 todo가 독점하도록 한다.
- 치수/공차 판정 PoC는 현재 1차 구현 todo에 포함하지 않는다.
- 검사 세션은 최신 DB 설계의 `INSPECTED.session`을 기준으로 API `sessionUuid` 계약을 고정한다.
- 동일 파일 수정 권한은 하나의 Worker에게만 부여한다.
