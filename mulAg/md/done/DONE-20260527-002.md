## QA 확인 내용

- review에 기록된 변경 파일과 실제 변경 파일이 일치한다.
- 각 Worker는 todo의 수정 가능 파일과 생성 가능 파일 범위 안에서만 작업했다.
- 제품 선택 화면에서 제품 카드 목록을 제거하고, 드롭다운을 단일 선택 상태로 유지했다.
- 바코드/QR 촬영은 별도 버튼 전환이 아니라 카메라 영역을 기본 흐름으로 노출하고, 인식 결과는 드롭다운 선택값에 반영하도록 구성했다.
- 검사 시작 버튼은 제품 선택 전 비활성화된다.
- 촬영 화면은 우측 보조 패널과 불필요한 썸네일을 제거하고, 지시는 촬영 영역 상단, 촬영/확정 액션은 촬영 영역 하단에 배치했다.
- 기준 사진 등록/관리는 관리자 화면으로 분리했다.
- 1280 x 800 viewport에서 제품 선택과 촬영 화면의 핵심 조작 영역이 viewport 안에 들어오는 것을 확인했다.
- `pnpm run lint`, `pnpm run test:run`, `VITE_BASE_PATH=/SANIL/ VITE_USE_MOCK_API=true pnpm run build`, `git diff --check` 통과가 필요하며, 최종 커밋 전 재실행한다.
