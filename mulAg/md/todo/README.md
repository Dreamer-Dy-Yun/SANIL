# Todo

## 역할

`todo/`는 Orchestrator가 작성하고 Worker(Sub-Agent)가 수행할 작업 단위를 보관한다.

## 필수 항목

- 1개 명확한 목적
- 1개 책임 영역
- 상태
- 참조 plan
- 선행 조건
- 수정 가능 파일
- 생성 가능 파일
- 읽기 전용 파일
- 수정 금지 파일
- 입력
- 출력
- 완료 기준
- 검증 기준

## 파일 권한 의미

todo의 수정 가능 파일과 생성 가능 파일은 해당 작업의 파일 점유 선언이다.

## 처리 기준

- 동일 파일을 여러 Sub-Agent가 동시에 수정해야 하는 todo는 병렬 배정하지 않는다.
- todo에 없는 파일 수정이 필요하면 review에 이슈로 남기고 후속 todo로 처리한다.
