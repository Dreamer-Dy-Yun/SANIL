# Capture Screen Design

## 결론

QA 대상 촬영은 스크롤 목록이 아니라 단계형 화면으로 만든다.

한 화면에는 하나의 촬영 개소만 보여준다.

고객 사용 장비는 `M86XE` 계열 태블릿으로 보고, 촬영 화면은 태블릿 현장 조작을 기준으로 설계한다.

이 화면은 작업자 기본 앱의 핵심 화면이다. 관리자 기준 사진 관리, 제품 카드 탐색, 데스크톱형 사이드바, 우측 보조 패널을 전제로 공간을 배정하지 않는다.

## 이유

- 현장 작업자가 지금 찍어야 할 대상 하나에만 집중할 수 있다.
- 기준 사진과 QA 대상 사진 매핑 실수를 줄인다.
- 촬영 누락을 라우팅/상태로 차단하기 쉽다.
- 진행 단계, 재촬영, 확정, 다음 이동이 명확하다.

## 화면 구성

촬영 화면은 상단 지시, 중앙 preview, 하단 action bar의 세 영역만 기본 구조로 둔다.

```text
┌────────────────────────────────────┐
│ 제품명 / 검사번호 / 3 of 7          │
├────────────────────────────────────┤
│ 촬영 지시                           │
│ 기준 사진명 + 작업 지시문            │
│                                    │
│                                    │
│         Camera Preview              │
│     + Reference Outline Overlay     │
│                                    │
├────────────────────────────────────┤
│ [재촬영] [촬영 확정]                │
└────────────────────────────────────┘
```

## 장비 기준

- 대상 장비: `M86XE` 계열 태블릿
- 화면 기준: 8 inch, 1280 x 800, 16:10 landscape
- 실제 OS, 브라우저, 카메라 사양은 실기 확인 전까지 확정하지 않는다.
- 버튼과 주요 조작 영역은 현장 사용을 고려해 충분한 터치 영역을 확보한다.
- 1280 x 800 landscape에서는 좌측 사이드바를 고정 노출하지 않는다. 촬영 중 탐색은 최소화하고, 필요한 경우 상단 메뉴 버튼과 일시적 drawer navigation으로 처리한다.
- 촬영 화면은 preview를 단일 작업 영역으로 두고, 촬영 지시는 preview 위, 촬영/확정 액션은 preview 하단에 둔다.
- 우측 기준 썸네일 패널이나 고정 보조 패널은 1차 현장 촬영 화면에서 제외한다.
- 화면은 portrait/landscape 양쪽에서 깨지지 않아야 하며, 실제 장비 viewport를 확인한다.
- 카메라 권한과 `getUserMedia` 동작은 실제 장비 브라우저에서 PoC로 확인한다.

## 주요 컴포넌트

| 컴포넌트 | 책임 |
|---|---|
| `CaptureStepPage` | 라우트 단위 촬영 화면 |
| `CaptureProgressHeader` | 제품명, 세션, 현재 단계/전체 단계 표시 |
| `CameraPreview` | 카메라 스트림과 캡처 이벤트 |
| `ReferenceOverlay` | 기준 사진 외곽선/가이드라인 표시 |
| `CaptureInstructionBar` | 촬영 영역 위에서 촬영 지시 표시 |
| `CaptureActionBar` | 촬영, 재촬영, 촬영 확정 버튼 |
| `CaptureProcessingBadge` | 개별 VLM 처리 상태 표시 |

## 버튼 상태

| 상태 | 재촬영 | 촬영 확정 | 다음 |
|---|---|---|---|
| 촬영 전 | 비활성 | 비활성 | 비활성 |
| 촬영 후 미확정 | 활성 | 활성 | 비활성 |
| 확정 후 처리 대기 | 활성 | 비활성 | 조건부 활성 |
| 확정 후 처리 중 | 활성 | 비활성 | 활성 |
| 확정 후 처리 실패 | 활성 | 비활성 | 활성, 결과 화면에서 실패 표시 |

개별 VLM 결과가 끝나지 않아도 다음 촬영으로 이동할 수 있다. 단, 최종 결과 화면은 모든 필수 촬영이 완료되어야 접근 가능하다.

## 오버레이 설계

1차 구현은 기준 사진 외곽선 기반 오버레이를 사용한다.

- 기준 사진 이미지 표시
- 투명도 조절
- 외곽선/정렬선 표시
- 중앙/모서리 기준선 표시

완전 자동 외곽선 추출은 제품/조명/배경에 따라 흔들릴 수 있으므로, 초기에는 수동 조정 또는 저장된 guide shape를 허용한다.

## 실패 처리

- 카메라 권한 없음: 촬영 불가 상태와 권한 안내
- 이미지 저장 실패: 다음 단계 이동 금지
- VLM 처리 실패: 다음 촬영은 허용, 최종 결과에서 `failed`로 표시
- 필수 기준 사진 누락: 검사 시작 금지

실패를 임시 성공 상태로 바꾸지 않는다.
