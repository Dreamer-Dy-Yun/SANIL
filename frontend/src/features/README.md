# Feature Screens

## 역할

`frontend/src/features/`는 라우트와 업무 흐름 기준으로 화면을 나눈다.

## 폴더 역할

| 경로 | 역할 | 갱신 기준 |
|---|---|---|
| `admin/` | 관리자용 기준 사진 등록/관리 화면 | 관리자 권한 화면과 운영 기능이 바뀔 때 |
| `auth/` | 로그인 화면 | 인증 입력/오류/전환 흐름이 바뀔 때 |
| `products/` | 검사 대상 제품 선택과 검사 시작 | 제품 선택, 바코드/QR 조회, 세션 생성 흐름이 바뀔 때 |
| `references/` | 제품별 기준 사진 조회와 guide 표시 요약 | 기준 사진 조회 계약과 guide 표시 요약이 바뀔 때 |
| `inspection/` | 단계형 촬영, 처리 대기, 결과, 이력 화면 | 검사 세션 흐름이나 결과 표시가 바뀔 때 |

## 경계 기준

- feature 화면은 API contract와 shared component만 사용한다.
- fixture, HTTP 세부 구현, 카메라 파일 생성 방식은 직접 알지 않는다.
- 필요한 데이터가 없으면 오류나 빈 상태를 드러내고 임의 값을 만들지 않는다.
